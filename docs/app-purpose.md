サービスの実際の動作（間隔、保存するもの、保存期間）と一致させること。動作を変えた場合はこの文書と提出内容を合わせて更新し、報告・再審査の要否を確認する。

```text
【概要】 kametchiは、特定のDJ1名（開発者が応援しているDJ。本人の同意を得ています）の配信を盛り上げる補助ボットです。利用者はDJ本人と開発者の2名だけで、2名が参加する非公開のDiscordサーバーから操作します。一般公開や他のDJへの提供は行いません。 プライバシーポリシー: https://kametchi.com/privacy 【機能】 ・DJの配信が始まったらDiscordに通知します。ボットは、Discordで「参加」を操作したときだけ配信に接続します。 ・無料ハートと有料ハート1個に、決まった文面のお礼をチャットに送ります（DJがオン・オフできます）。 ・Discordの決められたチャンネルにDJか開発者が書いた文章を、ボット名で配信のチャットに送ります。 ・DJが指定したリスナー（本人の了承を得た人だけ）のチャットから、ダジャレらしい発言を判定してDiscordに投稿し、2名で投票します。 【第三者での処理】 ダジャレと判定したチャット1件の本文と、発言者のニックネームを、上記の非公開Discordサーバーに投稿します。投票で却下されたものと、リスナー本人から要望があったものはその時点で、残りはDJの連携解除時にすべて削除します。 【保存するデータと保有期間】 ・DJのトークン（暗号化）と許可された権限、ハートのお礼のオン・オフ：連携解除まで ・ダジャレ判定の対象リスナーの識別子：連携解除まで、または本人から要望があるまで ・Discordに投稿したダジャレのメッセージID（削除に使います。本文は含みません）：連携解除まで ・APIのエラーログ：30日 チャット本文、イベントの原文、リスナーの活動履歴は保存しません。連携解除時はトークンを無効化し、ただちに削除します。 【リスナーへの配慮】 自動で送るのはハートのお礼だけで、連続したハートは1回のお礼にまとめます。データの削除や判定対象からの除外の要望は、Discordまたはプライバシーポリシーの窓口で受け付けます。 【セキュリティ】 Client Secretとトークンはサーバー側でのみ暗号化して保管し、ブラウザやログには出しません。
```

## メモ（提出しない）

- 公式ドキュメントでは用途欄の上限を200文字としているが、コンソールの上限は2000文字（Lens の仕様書 §2.2）。上の提出文は2000文字以内に収めている
- ハートコメントの30秒の待ち時間は廃止し、最小の制限にする（2026-10-15 ユーザー決定）。チャット送信の待ち行列（Lens の `src/bot/chat-sender.ts`、`minIntervalMs` 1.5秒）で間隔を空け、送信待ちのハートコメントがあるあいだは新しく積まない
- ダジャレ判定の対象リスナー本人の了承は得られている（2026-10-15 ユーザー確認）
- Discord に投稿したダジャレは期限を設けず残し、連携解除時にすべて削除する（2026-10-15 ユーザー決定）。実装要件: 投稿したメッセージの ID を DB に保持し、`/unlink` と連携解除の検知時に削除する（本文は保存しない）
- プライバシーポリシーは `https://kametchi.com/privacy` に置く想定（Lens の `src/web/privacy-view.ts` に倣う）
