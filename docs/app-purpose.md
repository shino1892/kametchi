登録画面の「アプリ目的」欄に、次の「提出文」をそのまま貼り付ける。サービスの実際の動作（間隔、保存するもの、保存期間）と一致させること。動作を変えた場合はこの文書と提出内容を合わせて更新し、報告・再審査の要否を確認する。

## 提出文

```text
【主目的】
特定のDJ1名（開発者が応援しているDJ。本人の同意を得ています）の配信を盛り上げる補助ボットです。利用者はDJ本人と開発者の2名だけで、2名が参加する非公開のDiscordサーバーから操作します。一般公開や他のDJへの提供は行いません。

【主な機能】
1. 配信開始の通知: DJの配信が始まったらDiscordに通知します。ボットは自動では入室せず、Discordで「参加」を操作したときだけイベントストリームに接続します。「退室」の操作か配信終了で切断します。
2. ハートのお礼: 無料ハート、または有料ハート1個が届いたとき、ボットが決まった文面のお礼をチャットに送ります。直前のお礼から30秒以内のハートには送らず、配信全体で30秒に1回までにします。DJはチャットのコマンドまたはDiscordからオン・オフできます。
3. Discordからのコメント送信: Discordの決められたチャンネルにDJまたは開発者が書いた文章を、ボット名で配信チャットに送ります（200文字以内）。
4. ダジャレ判定: DJが指定したリスナー（本人の了承を得た人だけ）のチャットを形態素解析し、ダジャレらしい発言をDiscordに投稿して、2名で投票します。

【権限ごとの用途】
・live.read: 配信の開始・終了の確認（30秒ごと）
・events.chat: DJのコマンドの解釈とダジャレ判定。チャットはメモリ上で処理し、保存しません
・events.like: ハートのお礼のきっかけ
・chat.send: ハートのお礼と、Discordから手動で送るコメント

【第三者での処理】
ダジャレと判定したチャット1件の本文と、発言者のニックネームを、上記の非公開Discordサーバーに投稿します。判定の対象は、本人の了承を得たリスナーだけです。投稿はDJの連携解除時にすべて削除します（投票で却下されたものはその時点で削除し、リスナー本人から要望があった場合も削除します）。

【保存するデータと期間】
・DJのアクセストークンとリフレッシュトークン（暗号化して保存）、許可された権限: 連携解除まで。解除時はトークンを無効化して直ちに削除します
・連携用の一時URLの状態: 10分で破棄
・ハートのお礼のオン・オフ設定: 連携解除まで
・ダジャレ判定の対象リスナーのID: 連携解除まで、または本人から要望があるまで
・Discordに投稿したダジャレのメッセージID（連携解除時の削除に使います。本文は含みません）: 連携解除まで
・APIのエラーログ: 30日
チャット本文、イベントの原文、リスナーの活動履歴はアプリのデータベースに保存しません。

【リスナーへの配慮】
自動で送るのはハートのお礼だけで、30秒に1回までに抑えます。リスナーへの告知は削除・遮断しません。入退室の告知が繰り返されないよう、接続は手動の操作でだけ行い、意図しない再接続を抑えます。削除や判定対象からの除外の要望には、Discordまたはプライバシーポリシーの窓口で対応します。
```

## メモ（提出しない）

- 公式ドキュメントでは用途欄の上限を200文字としているが、コンソールの上限は2000文字（Lens の仕様書 §2.2）。上の提出文は2000文字以内に収めている
- ダジャレ判定の対象リスナー本人の了承は得られている（2026-10-15 ユーザー確認）
- Discord に投稿したダジャレは期限を設けず残し、連携解除時にすべて削除する（2026-10-15 ユーザー決定）。実装要件: 投稿したメッセージの ID を DB に保持し、`/unlink` と連携解除の検知時に削除する（本文は保存しない）
- プライバシーポリシーは `https://kametchi.com/privacy` に置く想定（Lens の `src/web/privacy-view.ts` に倣う）
